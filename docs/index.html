NaharDrop

Send files between your phone and laptop over your own Wi-Fi - no cloud, no cables, no account.

Download

Grab the latest build for your laptop's OS. No install needed - just run it.

Windows (.exe) macOS (Apple Silicon)

Or see all releases. First run on macOS may need "right-click > Open" past Gatekeeper, since the binary isn't signed.

How it works

  1. Run NaharDrop on your laptop.
  2. Scan the QR code it prints with your phone's camera (same Wi-Fi network).
  3. Approve the device on your laptop when prompted.
  4. Drag files onto the dashboard to send them to your phone, or pick files on your phone to send them to your laptop.

Running from source

Prefer Python? Clone the repo and run:

pip install -r requirements.txt
python run.py

See the README for Docker, firewall tips, and hotspot-mode instructions.

NaharDrop runs entirely on your local network. No file ever leaves your Wi-Fi.
